# Native 本机模式 · 第一阶段验收

本次只改 Native。开屏现有密码验证和海岸信箱保持原样，新增“本机模式”。不实现同步、自动合并或迁移。

- 本机模式独立保存到 app-private noBackupFilesDir/coast-local-v1；在线模式原存储不变。
- 本机请求由终止型 OkHttp interceptor 在进程内执行，未知路径明确返回 501，错误 host 返回 403，永不回退云端。没有启动 HTTP 服务器，也不读取在线 cookie。
- 沿用 MainShell、ChatWindow、历史分支结构、个人资料与日常 UI。可新建/改名/删除窗口、记录文字、检索、日记与碳硅圈基础手动操作、导出当前已实现数据。
- 第一阶段不调用任何模型。聊天顶部标“本机模式 · 仅记录”，未连接模型的文字作为本机记录保存，不伪造回复。自动整理、附件、收藏、书房、语音等尚未移植。
- 模型 API、本机上下文编排、思维壤及记忆库、工具等作为后续阶段，不做云端兜底。
- 本机模式退出：小狼窝 → 账户 → 返回开屏。保留本机文件。重新进入仍在。
- 无真实数据、账号、密钥或私有海岸内容被提交。

## 真机验收

1. 保留现有安装及账号数据，安装预览 APK；在线模式登录及现有记录保持原样。
2. 从开屏选本机模式（无网络也可）。确认顶部模式标签、窗口列表不出现云端内容。
3. 本机新建窗口并写入测试文字，改名、搜索；写入测试日记。
4. 杀掉 app、打开，记录仍在；小狼窝返回开屏，再进入本机，记录仍在。
5. 切换在线模式后不出现本机测试内容；云端原记录不变。
6. 在本机尝试未迁移的操作，确认明确提示并且没有云端请求。
7. 导出本机快照，确认 included/excluded modules 诚实反映范围，不含在线数据。
8. 单元测试 LocalCoastTransportTest 验证隔离、持久化、检索、导出、未知路径失败以及禁止 DNS。

这不是完整本机版。验收后再将通用实现同步到开源仓库，不改 PWA 和部署后端。
