# 0.1.138

- 私人在线海岸：新增由已授权 Android 设备执行的套餐梦醒潮，无需切换本机工作区。在线窗口的设置、历史、工具回执、小笺与潮痕仍保存在原服务端；套餐凭据留在设备。
- 手机后台调度、窗口独立授权与撤销、请求预约去重、累计软预算、活动结算及在线小笺系统通知；点击通知可返回对应工作区。
- 本机模式和现有云端 API 模型调度路径保持独立。PWA 可查看在线活动、保存设置或撤销授权，不代手机授权套餐。
- 在线服务端需完成新代码部署并启用独立设备执行门；未启用时不得声称已能自动唤醒。系统强停、关机、断网与省电策略可使后台调度延迟或中断。
- 设备步数、应用使用数据及自主生图像素回传尚未接通，界面明确提示。原图仍可查看。
- 建议覆盖安装前导出完整归档；新设备或恢复归档后需重新授权。锁屏、实际套餐调用、保存结果和通知须真机验收。
